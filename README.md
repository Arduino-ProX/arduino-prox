# Arduino ProX

### Program Arduino, ESP32 and ESP8266 directly from Android.

Arduino ProX is an Android IDE for programming Arduino, ESP32 and ESP8266 boards directly from your Android device.

Whether you're a beginner learning Arduino or an experienced maker working on an embedded project, Arduino ProX provides the tools needed to write, compile and upload your projects from Android.

## 🚀 Features

- 🟢 Support for Arduino boards
- 🔵 ESP32 support
- 🟠 ESP8266 support
- 💻 Powerful code editor
- 🔌 USB / OTG programming
- 📦 Board SDK management
- 📚 Library support
- 🛠️ Project development tools
- 📱 Designed specifically for Android

## 📟 Supported Platforms

### Arduino

Arduino ProX supports Arduino boards across the Arduino platform, including classic and newer board families supported by the available Arduino cores.

### ESP32

Program ESP32 projects directly from your Android device.

### ESP8266

Develop and upload ESP8266 projects directly from your Android device.

## 📱 Why Arduino ProX?

Arduino ProX brings embedded development closer to your pocket.

You can:

1. Write your code
2. Compile your project
3. Connect your board using USB OTG
4. Upload your firmware
5. Continue developing directly from Android

No desktop IDE is required for supported workflows.

## 🐛 Support

If you encounter a problem while using Arduino ProX, please open an issue with as much information as possible.

Please include:

- Android device model
- Android version
- Arduino ProX version
- Board name
- SDK/platform
- What you were trying to do
- Complete error message
- Screenshot or log, if available

This helps the Arduino ProX team investigate the issue more efficiently.
