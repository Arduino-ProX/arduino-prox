# Getting Started with Arduino ProX

Arduino ProX lets you develop and program Arduino, ESP32 and ESP8266 projects directly from your Android device.

## What you need

Before getting started, make sure you have:

- An Android device
- Arduino ProX installed
- A supported development board
- A USB OTG adapter or compatible USB connection
- A suitable USB cable

## 1. Install Arduino ProX

Download Arduino ProX from Google Play:

[Download Arduino ProX](https://play.google.com/store/apps/details?id=com.microdev.arduinoprox)

## 2. Select your board

Open Arduino ProX and select the development board you want to program.

Arduino ProX supports:

- Arduino boards
- ESP32 boards
- ESP8266 boards

## 3. Install the required SDK

If the required SDK or board package is not available, use the SDK management options in Arduino ProX to install or reinstall it.

## 4. Create or open a project

Create a new project or open an existing Arduino project and write your code using the built-in code editor.

## 5. Connect your board

Connect your development board to your Android device using a compatible USB OTG connection.

Make sure the USB connection is detected correctly by Android.

## 6. Compile your project

Compile the project and check the build output for any errors.

If compilation succeeds, the project is ready to upload.

## 7. Upload your code

Connect the board and start the upload process.

If the upload fails, check the board selection, USB connection, permissions and SDK installation.

## Troubleshooting

If you encounter a problem:

1. Verify that the correct board is selected.
2. Check the USB OTG connection.
3. Make sure the required SDK is installed.
4. Try reinstalling the SDK from the app settings.
5. Check the build or upload output for error messages.

If the problem continues, [open an issue](https://github.com/Arduino-ProX/arduino-prox/issues) with your device model, Android version, board name and error details.
